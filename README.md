# Zabbix Network Monitoring

## About the Project

This project demonstrates the deployment of **Zabbix 7.0** on Ubuntu to monitor Linux hosts in a virtual environment.

The project includes:

- Installation and configuration of Zabbix Server
- Apache2 and MariaDB configuration
- Connection of RH and FINANCE clients
- CPU, Memory and Disk monitoring
- CPU Trigger (>90%)
- Automatic remediation using a Bash script
- Automatic Action execution
- Monitoring Dashboard

---

## Technologies

- Zabbix 7.0
- Ubuntu Linux
- Apache2
- MariaDB
- PHP
- Bash
- Oracle VirtualBox
